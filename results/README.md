# Results: run of 22 October 2026

A copy of the latest run (`runs/2026-10-22_213542_20y/`), in two parts:

- [`auctions/`](auctions/): auction results, one folder per country, plus
  [`global/`](auctions/global/) (every country together) and
  [`auction_totals.csv`](auctions/auction_totals.csv) (auctions per country
  and maturity bucket).
- [`market_yields/`](market_yields/): daily market yields, one folder per
  country that publishes them (10 countries), plus
  [`global/`](market_yields/global/) (all of them together).

- **Last 12 months**: every auction as it happened, plus the daily market
  yield where the country publishes one. Nothing is averaged.
- **20 years**: monthly medians smoothed with a 3-month average, by maturity bucket.

A dash means the country doesn't publish that measure (or, for market yields,
that no free daily source was found).
